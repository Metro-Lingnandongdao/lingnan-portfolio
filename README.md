# 嶺南東道 · 个人网站作品集版

一个无构建步骤的响应式静态网站，适合 GitHub Pages、Netlify 或 Cloudflare Pages。纯 HTML / CSS / JavaScript；大部分原有示意图为本地 SVG，新增“轨道百科”专题使用维基共享资源的远程图片与可选的维基百科公开表格接口。

## 当前包含

- 个人介绍与原创线路风格视觉：首页和关于板块。
- 视频专题展示：3 张专题卡片，可用顶部分类标签筛选。
- 线路图作品集：4 张原创矢量概念样稿，可按线网图、低运量系统、换乘关系、车站导视分类，并点击查看大图。
- 手机端导航与响应式卡片布局。
- 铁路官网按五个地区分组，支持筛选和关键词搜索。
- 无构建步骤，适合直接部署。

## 重要说明

视频卡片标题基于创作专题方向，用于展示作品集版式；目前尚未绑定已确认的单条 B 站稿件，因此卡片暂时指向 B 站主页。线路图 SVG 均为原创概念示意稿，虚构路线与节点，不是官方运营线路图，不能用于实际出行。替换为真实作品后，可删除卡片中的概念说明。

## 本地预览

双击 `index.html` 即可打开。若希望在本地服务器预览，在该目录运行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 将此文件夹中的所有内容（包括 `assets` 文件夹）上传到仓库根目录。
2. 确保 `index.html` 位于仓库根目录，而不是二级文件夹内。
3. 在仓库中打开 **Settings → Pages**。
4. 在 **Build and deployment** 中选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，然后保存。
5. 提交更新后，GitHub Pages 会自动重新发布。

## 怎么修改

### 修改文字、视频标题和链接

编辑 `index.html`。

每张视频卡片的标题在 `<h3>...</h3>` 中，描述在后面的 `<p>...</p>` 中。把卡片里两个 `href="https://space.bilibili.com/514708666"` 改成对应视频的完整 B 站链接，即可让封面和底部链接都打开指定视频。

视频筛选类别由 `data-video-category` 控制，可用值为 `rail`、`intercity`、`design`。

### 替换视频封面

把新封面文件放入 `assets/`，再把视频卡片 `<img src="assets/video-lrt.svg">` 的路径换成自己的 JPG、PNG 或 SVG 文件。建议所有封面保持接近 16:9 比例。

### 替换线路图作品

把线路图导出为 SVG、PNG 或 JPG，放进 `assets/`。每张作品卡片的预览图路径位于 `<img src="assets/map-network.svg">`，大图弹窗路径位于按钮的 `data-map-src="assets/map-network.svg"`；两处都要改成同一个新文件。

更改卡片标题和说明时，也需要更新该按钮的 `data-map-title`、`data-map-desc` 属性。分类值 `data-map-category` 可选 `network`、`lrt`、`transfer`、`guide`。

### 修改颜色与样式

编辑 `style.css`。文件顶部的 `:root` 中存放基础颜色变量，文件后段的 redesign 区域控制扁平化卡片、导航下拉和铁路官网目录。

### 修改交互

编辑 `script.js`。这里包括手机导航、下拉菜单、视频筛选、线路图筛选、作品大图弹窗、铁路官网搜索/地区筛选与页脚年份。

## 图片与视频加载修复

- 网站文件以 ZIP 根目录结构打包，上传时把此目录中的网页文件和 `assets/` 放入仓库的网站根目录，不要额外套 `lingnan_edit/` 文件夹。
- `asset-recovery.js` 为无法读取的本地图、外链图及动态加载图提供回退，避免空白图片框。
- 视频页优先读取本地缓存的 B 站公开元数据和封面；仓库含 `.github/workflows/update-bilibili-covers.yml`，首次上传后可到 **Actions** 手动运行 `Refresh Bilibili video covers`，也会每月尝试更新。它仅获取公开元数据与封面缩略图，不下载视频内容。运行是否成功取决于 GitHub Actions 的网络访问以及 B 站接口限流。
- B 站内嵌播放器受平台和浏览器策略影响；无法在本站播放时，请使用播放器画面右下角的原视频链接。
- 图片和线路图来源、版权说明见 `IMAGE-SOURCES.md`。

### B站视频标题与封面缓存

`videos.html` 优先读取 `assets/bilibili-video-metadata.json` 中由 GitHub Actions 缓存的公开元数据。将本次更新推送到 GitHub 后，`.github/workflows/update-bilibili-covers.yml` 会尝试读取 B 站公开信息并下载封面缩略图（不下载视频文件）。也可以在仓库的 Actions 页面手动运行 `Refresh Bilibili video covers`。如果 B 站限制访问，工作流会显示失败日志；页面保留原视频链接和占位封面。
